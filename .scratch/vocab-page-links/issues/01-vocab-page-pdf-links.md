# 01: 教材词表页 PDF 与词源索引一键跳转

**项目票号（会话标题用）：** `#09`
**Type:** task
**Status:** ready-for-agent

## 目标

用户在 EggplantDict 查到词后，可从该词的每条教材出处一键打开**实际印有这个词的完整原书页面**，保留教材的版面、课文、注释与页码，方便核对并保有阅读书页的感觉。默认展示每册无损词表页 PDF 中的完整原页；二次识别使用派生的词表区域裁图。覆盖当前索引中的人教版 12 册与经典版新概念英语 1–4 册。先完成本机可用的端到端流程，不发布教材扫描件。

## 范围与数据契约

1. 从 16 册原书抽出**所有属于教材词表的完整页及必要续页**，排除不含词表的目录、纯练习、纯注释等误判页。保留收录页面的完整版面和原有清晰度，每册一份无损 PDF，16 册共 16 份；每份按原书顺序汇集该册全部词表页。建议稳定文件名 `<book_id>-vocab.pdf`；已保存的新概念快照可直接复用。输出到 Git 仓库外的可配置本机目录，原书和快照 PDF 都不提交 Git。
2. 生成机器可读清单：稳定 `pdf_id`（建议 `book_id`）、相对文件名、源 PDF 标识/校验值、快照页序（从 1 起）、源 PDF 页序（从 1 起）、印刷页码、关联 Unit/Lesson、首页/续页角色。快照页序是抽页后 PDF 的页序，源 PDF 页序是原书文件的页序，印刷页码是书页上印出的数字；三者分别记录。源书版本或页数变化时拒绝套用旧映射，提示复核。
3. 让每条**已核实的词源命中**可解析到 `pdf_id` 和快照页序；同词跨册、跨课、跨页时保留各自目标。新概念不能只按 Lesson 指向首词表页，须核实续页上的具体词。人教不能仅按 `p.` 正文页码推断附录词表页。未核实或有歧义的命中保留现有出处信息，但不生成假链接，并汇总待核数量。
4. 设计明确的索引版本/兼容方案，避免现有 `v:1` 三段或四段 hit 被旧消费端静默误读。`pdf_id` 与目标页必须通过正式索引或其同版本、可校验的页码映射解析，不能只存在于人工 CSV；保留现有册、Unit/Lesson、中文释义和多 hit 语义。记录可复跑的生成命令与数据来源。
5. 为二次识别准备词表区域裁剪规则与可复跑的导出命令。区域保留完整词条的词头、音标、词性、释义及换行内容，保留适量边距；双栏可分别记录区域与阅读顺序，续页独立记录并关联原课次。区域信息与原页映射保存位置见下节。裁图可以按需重建，供后续 OCR/视觉转录使用；本票不以裁剪本身作为识别准确率提高的证明，也不改变人教 #05 当前采用整页视觉转录的要求。
6. EggplantDict 在每条出处旁提供可点击入口，读取本机裁页目录并**直接打开精确的完整原页**（可用 PDFKit 定位页，不能依赖未验证的外部 PDF `#page=` 行为）。用户默认看到原书整页，保留课文、注释等上下文。多条出处可分别打开；文件丢失或目录迁移时给出重连入口/明确提示，不显示无效链接。首次选择目录后应记住位置。

## 二次处理资料的保存位置

以下为本票待实现的保存约定，当前尚未生成统一映射与区域裁图。

- **已核对的页面与区域映射：**统一保存在 `data/vocab/vocab-page-map.json`，作为可纳入 Git 的生成依据。记录映射版本、`book_id`/`pdf_id`、相对 PDF 文件名、源书校验值、原 PDF 页序、快照页序、印刷页码、Unit/Lesson、首页/续页角色，以及稳定 `region_id`、区域框和阅读顺序。区域框采用原页可见方向、左上角为原点的归一化坐标，并明确页面尺寸与旋转处理，使不同渲染分辨率下仍可重建。现有新概念 `vocab_page_map.json` 是迁移依据；统一清单建立后生成器使用统一来源，避免维护两份冲突的页码表。
- **区域裁图与后续识别候选：**保存到被 Git 忽略的 `data/vocab/_work/vocab-page-regions/<book_id>/`。裁图使用 `region_id` 命名；候选 JSON 引用 `region_id`、映射版本与源书校验值，记录识别工具/模型、参数和复核状态。本票准备裁图与映射，具体词性、音标、释义转录由后续任务产生。
- **用户阅读的 PDF：**保存在仓库外的可配置本机目录。现有新概念路径仍可复用。消费端通过第 4 条的索引/映射版本契约定位完整页面；需要随 PDF 提供的运行清单由统一映射生成，不依赖 `_work/` 中的裁图或候选。目录迁移不会要求用户重新进行 OCR。

- [ ] 对全部现有词源命中生成覆盖率报告：已验证并有精确页链接、无原页证据、歧义/疑似假词分别计数；已验证链接均落在实际印有该词的页。人教 #05 尚未完成的部分不可标成已验证。
